# lambda2color Agent Instructions

## Purpose
A Python library to transform a given light wavelength into the corresponding RGB color.

## Developer Commands
- Install for development: `make install_dev`
- Find TODOs/FIXMEs: `make todo`
- Generate PDF from notebook: `make <name>.pdf` (e.g., `make lambda2color.pdf`)
- PyPI release flow: `make pypi_all` (tags and uploads)

## Project Structure
- Source code: `src/lambda2color/`
- Metadata & dependencies: `pyproject.toml`
- Examples & docs: `README.md`, `README.ipynb`

## Conventions
- Uses `setuptools` with `src` layout.
- Version is defined in `src/lambda2color/__init__.py` and `pyproject.toml`.
- Indentation: 2 spaces (per `.editorconfig`).
- Code Style: Use concise, minimal comments; avoid redundant explanations.
- Language: English.
